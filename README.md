#  AtmoSync: Micro-Climate Arbitrage Analytics (Group 25)

## Project Overview
AtmoSync analyzes micro-climate conditions, IoT sensor readings, market prices, and route/shipment logistics to identify profitable arbitrage opportunities and optimize transport margins.

## Team Workflow & Key Findings
- **Data Cleaning & Preprocessing:** Standardized raw data into 5 clean core datasets (`Container_Details`, `IoT_Sensor_Data`, `Market_Prices`, `Route_Details`, `Shipment_Details`).
- **Exploratory Data Analysis (EDA):** Evaluated **522 total price comparison records** and **212 complete shipment records** with transport cost data, identifying **193 positive-margin** and **19 negative-margin** opportunities.
- **Data Visualization:** Created 12 analytical charts covering price arbitrage, route scenarios, container capacity, and sensor trends.
- **Dashboard & Documentation (Weeks 3–4):** Building an interactive Power BI dashboard from the 7 analytical datasets and compiling complete project documentation.

## Datasets Used for Dashboard
- `arbitrage_all_opportunities.csv`
- `city_product_prices.csv`
