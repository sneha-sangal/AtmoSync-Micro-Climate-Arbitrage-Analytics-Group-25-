# AtmoSync - Dataset Guide

## Overview
This guide describes the seven CSV datasets used in the AtmoSync project.

## Dataset Details

1. **arbitrage_all_opportunity.csv**
   Contains data related to potential arbitrage opportunities.

2. **city_product_price.csv**
   Contains product price information across different cities.

3. **container_capacity_summary.csv**
   Contains container types and their capacity details.

4. **route_cost_scenarios.csv**
   Contains estimated minimum and maximum route cost information.

5. **same_day_price_comparison.csv**
   Contains same-day product price comparisons and potential price gaps.

6. **sensor_container_combined.csv**
   Contains sensor readings such as temperature, humidity, and vibration for containers.

7. **shipment_analysis_data.csv**
   Contains shipment details, transport modes, routes, and expected transit information.

## Purpose
These datasets support data visualization, price comparison, shipment analysis, sensor monitoring, and dashboard development.

## Note
The datasets should be used as the source of data for the project dashboard. All calculations and interpretations should be verified against the original data.
