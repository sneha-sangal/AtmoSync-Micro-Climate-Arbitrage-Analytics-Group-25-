# AtmoSync - Data Visualizations

## Overview
This folder contains the data visualization work for the AtmoSync project.

The objective is to represent shipment, sensor, and market price data through clear and meaningful charts.

## Visualization Objectives
- Analyze temperature and humidity trends.
- Visualize IoT sensor readings.
- Compare shipment-related data.
- Analyze market price variations.
- Identify useful patterns and trends.

## Tools
- Python
- Pandas
- Matplotlib
- Seaborn

## Planned Visualizations
1. Temperature Analysis
2. Humidity Analysis
3. Sensor Data Trends
4. Shipment Analysis
5. Market Price Comparison
